# Obsidian Books 0.2.0

Obsidian Books 0.2.0 adds separate, vault-native collection exports for every
saved highlight and every saved quote.

## Highlights

- Run **Export all highlights** to create or refresh
  `Obsidian Books/Exports/All Highlights.md`.
- Run **Export all quotes** to create or refresh
  `Obsidian Books/Exports/All Quotes.md`.
- Use either command from the command palette or its matching button under
  **Settings → Obsidian Books → Quotes and annotations**.
- Browse exported entries grouped by book and chapter.
- Retain selected text, source links, headings, capture dates, normalized reading
  locations, and `obsidian://books-open` links.
- Follow saved quotes back to their original Markdown destination when one is
  recorded.
- Refresh managed collection notes without accumulating duplicate snapshots.
- Preserve an unrelated note at a standard export filename by creating a
  timestamped export instead.
- Keep the current page centered during an iPad or mobile touch gesture, then
  snap the destination page into the same frame without dragging the full text
  strip across the screen.
- Keep bookshelf covers, wrapped two-line titles, metadata, and progress bars
  contained within each responsive iPad grid column.

## Validation

- Formatting, ESLint, strict TypeScript, 30 unit tests, and the production build
  pass.
- Automated tests cover separate highlight and quote collections, deterministic
  book/chapter grouping, metadata and reopen links, managed-file detection, and
  collision-safe timestamped paths, plus horizontal swipe intent and page
  direction.
- Dedicated-vault runtime results are recorded in the repository test checklist.

## Install or update

Install the release through BRAT with:

`https://github.com/jajuangarrett-ctrl/obsidian-books`

For manual installation, copy `main.js`, `manifest.json`, and `styles.css` from
this release into `.obsidian/plugins/obsidian-books/`, then restart Obsidian or
reload the plugin.
