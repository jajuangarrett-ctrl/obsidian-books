# Obsidian Books 0.2.5

Obsidian Books 0.2.5 adds a chapter-level table of contents built from the
headings and subheadings in the page you are reading.

## Highlights

- Choose **Section table of contents** immediately after the quote button at the
  far right of the reader toolbar.
- Browse a touch-friendly H1–H6 outline that preserves the chapter's section and
  subsection hierarchy.
- Jump directly to the selected heading in paginated or vertical reading mode.
- Keep the existing **Contents** panel for book chapters, bookmarks, and saved
  annotations.
- Exclude headings inside embedded notes so the outline stays scoped to the
  active source chapter.
- See a clear empty state when a chapter has no headings to list.

## Validation

- Formatting, ESLint, strict TypeScript, 46 unit tests, and the production build
  pass.
- Automated tests cover heading normalization, nested and skipped heading
  levels, page mapping, scroll-position mapping, and boundary clamping.
- Focused acceptance in the dedicated `obsidian-books-test` vault confirmed the
  toolbar placement, hierarchy, embedded-heading exclusion, and paginated and
  vertical section jumps.
- Physical iPad and VoiceOver feel remain the final device confirmation.

## Install or update

Install or update the release through BRAT with:

`https://github.com/jajuangarrett-ctrl/obsidian-books`

For manual installation, copy `main.js`, `manifest.json`, and `styles.css` from
this release into `.obsidian/plugins/obsidian-books/`, then restart Obsidian or
reload the plugin.
