# Obsidian Books 0.2.1

Obsidian Books 0.2.1 makes highlighting touch-first and prevents text selection
from being mistaken for a page turn.

## Highlights

- Choose the highlight button with no active selection to turn on highlight
  mode.
- Drag across text with a finger, Apple Pencil, or mouse to preview the selected
  range in yellow and save it automatically when you lift.
- Keep highlight mode on for repeated annotations; choose the button again or
  press Escape to exit.
- Continue using the original select-then-highlight workflow when preferred.
- Keep native text selection and marker drags out of horizontal page-turn
  handling.
- Preserve the current paginated page or vertical scroll location when a
  highlight is saved.
- Leave source Markdown unchanged and retain the existing resilient annotation
  anchors and collection export workflow.

## Validation

- Formatting, ESLint, strict TypeScript, 36 unit tests, and the production build
  pass.
- Automated gesture tests cover touch, Apple Pencil-style pen, and mouse input,
  deliberate-drag detection, and page-swipe exclusion.
- Dedicated-vault runtime testing covered forward and reverse marker drags plus
  the original native-selection workflow on page 2 of 5 without a page jump.
- Physical iPad and Apple Pencil feel remain the final device confirmation.

## Install or update

Install or update the release through BRAT with:

`https://github.com/jajuangarrett-ctrl/obsidian-books`

For manual installation, copy `main.js`, `manifest.json`, and `styles.css` from
this release into `.obsidian/plugins/obsidian-books/`, then restart Obsidian or
reload the plugin.
