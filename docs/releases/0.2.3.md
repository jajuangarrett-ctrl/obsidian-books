# Obsidian Books 0.2.3

Obsidian Books 0.2.3 lets one highlight continue naturally across paginated
page breaks.

## Highlights

- Highlight the visible portion of a passage, then choose **Continue highlight
  on next page** in the bottom action bar.
- Drag across the remaining text after the reader advances one page.
- Repeat the continuation action for passages spanning more than two pages.
- Save both selected fragments and the intervening text as one continuous,
  resilient annotation.
- Choose **Done** when finished, or **Cancel** during continuation to retain the
  portion already saved.
- Choose an existing saved highlight to reopen its actions later.
- Use the same workflow with touch, Apple Pencil, mouse, or native text
  selection.

## Validation

- Formatting, ESLint, strict TypeScript, 41 unit tests, and the production build
  pass.
- Automated tests cover page eligibility, reversed fragment order, continuous
  offset merging, intervening text, and resilient anchor recovery after nearby
  edits.
- The production build was loaded in the dedicated `obsidian-books-test` vault.
- Physical iPad and Apple Pencil feel remain the final device confirmation.

## Install or update

Install or update the release through BRAT with:

`https://github.com/jajuangarrett-ctrl/obsidian-books`

For manual installation, copy `main.js`, `manifest.json`, and `styles.css` from
this release into `.obsidian/plugins/obsidian-books/`, then restart Obsidian or
reload the plugin.
