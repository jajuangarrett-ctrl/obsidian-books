# Obsidian Books 0.2.2

Obsidian Books 0.2.2 adds a non-destructive way to remove books from the
bookshelf.

## Highlights

- Use the clearly labelled **Remove from bookshelf** button beneath any book
  card.
- Hide recently opened, explicitly marked, and `Book.md` folder books.
- Keep the source Markdown, reading position, bookmarks, highlights, quote
  notes, and exported collections unchanged.
- Reopen a hidden note or book in Obsidian Books to restore its shelf card
  automatically.
- Keep hidden-book records synchronized across source renames and remove stale
  records when their source is deleted.
- Treat bookshelf visibility independently from annotations, so deleting a
  highlight or quote no longer needs to affect the shelf.

## Validation

- Formatting, ESLint, strict TypeScript, 38 unit tests, and the production build
  pass.
- Automated tests cover hidden-book persistence normalization and visible-book
  filtering.
- Dedicated-vault runtime testing removed one book from a five-card shelf while
  preserving its Markdown source, seven annotations, one bookmark, and 25%
  reading position.
- Reopening that note restored its shelf card, page 2 of 5 position, and visible
  highlight.

## Install or update

Install or update the release through BRAT with:

`https://github.com/jajuangarrett-ctrl/obsidian-books`

For manual installation, copy `main.js`, `manifest.json`, and `styles.css` from
this release into `.obsidian/plugins/obsidian-books/`, then restart Obsidian or
reload the plugin.
