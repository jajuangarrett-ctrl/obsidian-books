# Obsidian Books 0.2.4

Obsidian Books 0.2.4 lets each vault choose where managed highlight and quote
exports are stored.

## Highlights

- Set a vault-relative **Export folder** under
  **Settings → Obsidian Books → Quotes and annotations**.
- Keep the existing `Obsidian Books/Exports` location by default for backward
  compatibility.
- Store both **All Highlights.md** and **All Quotes.md** beneath the configured
  folder.
- Preserve collision-safe timestamped exports in that same configured folder.

## Validation

- Formatting, ESLint, strict TypeScript, 42 unit tests, and the production build
  pass.
- Automated tests cover migration fallback, configured-folder persistence,
  slash normalization, and standard and timestamped paths.

## Install or update

Install or update the release through BRAT with:

`https://github.com/jajuangarrett-ctrl/obsidian-books`

For manual installation, copy `main.js`, `manifest.json`, and `styles.css` from
this release into `.obsidian/plugins/obsidian-books/`, then restart Obsidian or
reload the plugin.
